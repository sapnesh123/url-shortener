# Project notes for Claude

## AI_LOG.md (required)

After every development step, append a short, factual entry to `AI_LOG.md` (keep its existing numbering and format):

- **Prompt:** the user's actual request (quote it verbatim)
- **AI suggested:** what was recommended
- **Changed:** what was actually changed, with file names. Also list suggestions that were *not* applied.
- **Tested:** what was actually run and its real results. Write "Nothing" if nothing was tested.

Never invent or embellish anything: no untested results, no changes that weren't made, no paraphrased results presented as output. If unsure whether something happened, leave it out or ask.
